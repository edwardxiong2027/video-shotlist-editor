# Video Shotlist Editor

Turn a video idea into a shootable sequence with a hook, visual proof, pacing, and a clean ending.

**Author:** Edward Xiong  
**Format:** Portable Agent Skill (`SKILL.md`)  
**Updated:** October 6, 2026

## Use it

Copy `SKILL.md` into an agent skill directory supported by your tool, or paste the starter prompt into a chat model and replace the bracketed inputs. The instructions are model-agnostic.

## What it does

Planning a short video, tutorial, or social clip.

## Workflow

1. Decide the viewer promise in one sentence.
2. Open with a question or visible result.
3. Match each spoken beat to footage or graphics.
4. Track rights, accessibility, and production limits.
